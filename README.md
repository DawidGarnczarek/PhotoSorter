# Photo Sorter

A simple macOS desktop app for manual photo selection. Browse images in a source folder, copy selected ones to a target folder with Space, move unwanted ones to Trash with Backspace. Navigate with arrow keys. Fullscreen with F. Mouse wheel to zoom.

## Setup

```bash
pip install -e .
```

## Run

```bash
photo-sorter
```

## Requirements

- Python 3.12+
- PySide6
- Pillow
- pillow-heif
- send2trash
